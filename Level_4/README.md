### Level 4 - MapReduce - Basic paradigm, combiner and comparison with python.

- Task_0 - Configuring the Hadoop platform on a computer using WSL. The following tasks were performed using the MapReduce paradigm.
- Task_1 - Calculating the share of fully vaccinated individuals relative to the population of each country using the MapReduce Mapper and Reducer.
- Task_2 - Calculating the average daily number of new infections per country using the MapReduce Mapper and Reducer.
- Task_3 - Calculating the number of days with school and workplace closures for each country using the MapReduce Mapper and Reducer.
- Task_4_Combiner - Extending all previous programs by adding a Combine step. Considering the feasibility of using it.
- Task_5_Python - Performing data analysis using the Python map, filter, and reduce functions instead of MapReduce. Presenting the similarities and differences between these built-in functions and MapReduce.
