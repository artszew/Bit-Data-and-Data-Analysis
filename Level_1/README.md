### Level 1 - Data Cleaning and Acquisition.

1. Access the COVID-19 data via Google Cloud's BigQuery API and download the data to DataFrane.
2. Explore the data – verify how many rows and countries the data covers, how daily data for countries is recorded, what types of numerical values the data contains, the time period of the collected data, and five other pieces of information you can create without any additional calculations.
3. Extract data on basic information for individual countries, rates of illness, deaths, vaccinations, and testing, as well as additional information you have selected yourself.
4. Append data on population, GDP, unemployment, murder rate, and inflation to the created DF/.csv file.
5. The final file will be used for further analysis in subsequent levels, so ensure the consistency of the data stored in it.

### Poziom 1 - Oczyszczanie i zgromadzenie danych.

1. Uzyskanie dostępu do danych na temat COVID-19 poprzez usługę BigQuery API Google Cloud i pobranie danych do DataFrane.
2. Poznanie danych - sprawdzenie ile wierszy i krajów dotyczą dane, w jaki sposób zapisywane są dane dzienne dla krajów oraz jakiego rodzaju wartości liczbowe zawierają dane, a także jaki jest przedział czasowy zebranych danych i 5 innych, wymyślonych samodzielnie informacji możliwych do uzyskania bez wykonywania żadnych dodatkowych obliczeń.
3. Wyłuskanie danych dotyczących podstawowych informacji na temat poszczególnych krajów, wartości zachorowań, zgonów, szczepień i przeprowadzanych testów, a także samodzielnie wybranych dodatkowych informacji.
4. Dołączenie do utworzonego DF/pliku .csv danych dotyczących populacji, PKB, bezrobocia, współczynnika morderstw i inflacji.
5. Utworzony końcowo plik będzie służył do dalszych analiz w kolejnych poziomach, więc należy zadbać o spójność zapisywanych w nim danych.
